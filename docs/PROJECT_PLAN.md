## 一、项目章程

### 1.1 一句话定义

用 6 周时间，独立完成一项**可复现、可证伪、经得起追问**的 A 股短期反转实证研究，并形成可用于求职展示的代码仓库、研究报告与面试叙事。

### 1.2 成功标准

| 维度 | 成功标准 | 验证方式 |
|---|---|---|
| 研究 | 四个假设都有明确结论（支持/不支持/无法判断） | 报告中的结论表 |
| 方法 | 无未来函数、无混池、复权口径统一 | 代码审查 + 测试 |
| 工程 | 从原始数据到最终结果一键复现 | 换机器按 README 重跑 |
| 表达 | 10–15 分钟能讲清问题、方法、证据、局限 | 模拟面试 |
| 求职 | 简历 bullet 均有事实支撑，不夸大 | 对照 `docs/RESUME.md` |

### 1.3 范围

**范围内**

- 沪深 A 股日线数据（2015–2025）
- 1/5/20 日形成期 × 1/2/5 日持有期
- 逐日横截面分组、t 检验、成本敏感性、行业调整、市场状态、样本外
- 研究报告、图表、可复现代码、数据质量报告

**范围外**

- 分钟级/高频数据、订单簿
- 机器学习模型、多因子合成
- 实盘交易、券商接口
- 北交所、可转债、ETF、基金

### 1.4 关键干系人

| 角色 | 人 | 职责 |
|---|---|---|
| 项目负责人/研究员/开发 | CyCloud | 全部执行 |

| 验收人 | CyCloud（自检）+ 模拟面试官 | 按验收清单逐项检查 |

## 二、交付物与验收标准

### 2.1 六项交付物

| 编号 | 交付物 | 内容 | 验收标准 |
|---|---|---|---|
| D1 | 研究报告 | 动机、假设、数据、方法、结果、局限 | 结论与证据一一对应，局限不隐藏 |
| D2 | 可复现代码 | 原始数据 → 最终报告的完整流程 | 按 README 可从零重跑 |
| D3 | 数据质量报告 | 缺失、异常、复权、公司行为、样本偏差 | 每个异常有处理说明 |
| D4 | 实验结果表 | 信号 × 持有期 × 市场状态 × 成本 | 9 组参数全报，不只报最优 |
| D5 | 风险分析 | 收益、波动、回撤、换手、成本、样本外 | 毛收益与净收益同时报告 |
| D6 | 项目演示 | 10–15 分钟讲解 | 能回答“为什么可信/为什么可能错” |

### 2.2 四条硬标准

1. **无未来数据泄漏**：信号时点、成交时点、未来收益标签三者时间关系可逐条核查。
2. **结果可复现**：固定数据版本、参数、随机种子；同一配置能重建同一结果。
3. **成本与风险完整**：不只报毛收益，必须报净收益、换手、最大回撤、成本敏感性。
4. **结论经得起反驳**：若策略失效，能定位原因；若有效，能说明边界条件。

### 2.3 质量门禁（每个里程碑必须通过）

- [ ] 代码可运行，无报错
- [ ] 新增逻辑有中文注释，变量名为英文
- [ ] 输出表头为中文，列宽/小数位/百分比格式统一
- [ ] 结果文件可追溯到代码版本与参数
- [ ] 更新 `PROJECT_MEMORY.md` 的“当前状态”
- [ ] 提交信息符合 Conventional Commits

## 六、汇报与协作机制

### 6.1 节奏

| 频率 | 动作 | 产出 |
|---|---|---|
| 每周五 | 更新周报 | `docs/reports/YYYY-MM-DD-weekN.md` |
| 每周五 | 更新记忆文档状态 | `PROJECT_MEMORY.md` 第 7、8、9 节 |
| 每个里程碑 | 质量门禁自检 | 门禁清单打勾 |
| 每次口径变更 | 追加决策记录 | `PROJECT_MEMORY.md` 第 3 节 |
| 每次提交 | Conventional Commits | `feat/fix/docs/chore/test` |

### 6.2 周报模板

```text
# 第 N 周周报（YYYY-MM-DD）
1. 本周结论（一句话）
2. 完成事项（表格：任务 / 产出 / 验收）
3. 关键数字（数据量、实验结果、耗时）
4. 偏差分析（计划 vs 实际，原因，影响，纠偏）
5. 风险与阻塞（需要决策的事项）
6. 下周计划（P0/P1/P2 + 验收标准）
7. 经验教训（方法、工程、时间管理）
```

### 6.3 决策升级规则

遇到以下情况必须暂停并向“研究顾问”确认，不自行决定：

- 改变研究问题、市场范围、样本区间
- 改变统计口径（如混池 vs 逐日）
- 发现结果与预期相反且影响结论
- 数据源出现无法解释的缺失或价格跳变
- 时间预算可能超出 8 周

## 八、当前最重要的三件事

1. **全市场数据 + 后复权**：没有这一步，后面所有统计都没有意义。
2. **用全样本重跑 9 组实验**：验证 5/5、20/5 的负号是现象还是小样本噪声。
3. **补测试与成本模型**：这是“研究”与“作业”的分界线，也是面试最容易被追问的地方。
