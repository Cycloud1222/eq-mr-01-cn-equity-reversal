## 0. 30 秒版本

EQ-MR-01 是一个**用于证明量化研究能力**的独立项目，不是实盘策略。

研究问题：**A 股是否存在可交易的短期反转效应？它在什么市场状态下更强？扣除交易成本后是否仍然存在？**

下一步：用新面板重算信号与全样本统计，补齐可交易约束、成本与统计修正，再做 2022–2025 样本外检验。

## 1. 目标与非目标

### 1.1 目标

| 优先级 | 目标 | 验收方式 |
|---|---|---|
| P0 | 完整走通“假设 → 数据 → 实验 → 结论”的量化研究闭环 | 六项交付物齐全 |
| P0 | 结论可复现、可解释、经得起反驳 | 换一台机器能重跑；每个数字能追溯到代码与参数 |
| P0 | 形成可用于简历与面试的项目叙事 | `docs/RESUME.md` 中的 bullet 均有事实支撑 |
| P1 | 掌握 pandas / NumPy / 统计检验 / 回测的工程化用法 | 能独立解释每一行核心代码 |
| P2 | 若结果支持，再扩展分钟级或更多因子 | 仅在日线结论稳定后启动 |

### 1.2 非目标（明确不做）

- 不追求“漂亮收益曲线”，不为了显著性反复调参数。
- 不做高频、订单簿、做市、低延迟。
- 不预设“反转一定存在”；结论可以是“不存在”或“扣费后消失”。
- 不做实盘、不接券商交易接口。
- 不把机器学习模型当作第一阶段的捷径。

## 3. 决策链（为什么是现在这个样子）

> 记录格式：背景 → 备选 → 决定 → 理由 → 后果。面试时按这条链讲，比背结论有效。

### D1. 股票还是期货？

- **背景**：用户需要在股票与期货之间选一个主战场。
- **备选**：股票（因子/横截面/统计套利）；期货（趋势/期限结构/动态仓位）。
- **决定**：股票。
- **理由**：股票数据可得性高、横截面样本多、统计检验框架成熟，适合个人在 4–8 周内做出完整研究。
- **后果**：必须处理复权、停牌、涨跌停、T+1、幸存者偏差等 A 股特有问题。

### D2. 低频、中频还是高频？

- **背景**：频率决定数据量、工程难度与可信度。
- **备选**：低频（日线到月度）；中频（分钟到数日）；高频（逐笔/订单簿）。
- **决定**：中频，落地为日线。
- **理由**：日线数据免费可得，能覆盖 1–5 日持有期，既保留“短期反转”的研究价值，又不至于陷入数据工程。
- **后果**：无法研究日内反转；持有期重叠会带来自相关，t 值必须修正。

### D3. 课题 A/B/C/D 选哪个？

- **背景**：ChatGPT 给出四个候选：多因子选股、期货趋势、股票统计套利、订单流。
- **决定**：**短期反转 + 市场状态识别**（课题 C 的变体）。
- **理由**：
  1. 问题可证伪：反转不存在或扣费后消失，都是合格结论；
  2. 数据要求低：日线收盘价即可构造信号；
  3. 能展示完整闭环：假设、分组、显著性、成本、稳健性、样本外；
  4. 研究空间足够：形成期、持有期、行业、市场状态都可扩展。
- **后果**：必须诚实报告“反转可能不存在”，不能为了简历硬造结论。

### D4. 美股还是 A 股？

- **背景**：ChatGPT 最初建议美股（数据长、文献多），用户后来改选 A 股。
- **决定**：**A 股**。
- **理由**：用户明确要求；A 股是求职目标市场；本地数据源更贴近实际。
- **后果**：文献参数不能直接照搬；必须重新处理复权、涨跌停、停牌、T+1；样本期缩短到 2015–2025。

### D5. 数据源怎么组合？

- **背景**：免费源各有覆盖与限流问题。
- **决定**：BaoStock 为主，AKShare 为校验/备份，Tushare Pro 仅在确有权限时使用。
- **理由**：BaoStock 提供日线、复权、交易状态；AKShare 可做交叉验证；避免把研究绑在单一接口。
- **后果**：必须记录下载时间、接口参数、记录数、文件哈希；不同源的数据不能混用。

### D6. 统计口径：跨日混池还是逐日横截面？（重要修正）

- **背景**：初版把所有交易日的数据混在一起做 30%/70% 分位。
- **问题**：不同日期的收益水平不同，混池会让“某几天的极端行情”主导分组，产生虚假结果。
- **决定**：改为**每个交易日独立做横截面分位**，再对每日收益差做时间序列汇总。
- **理由**：反转是横截面现象，必须在同一时点比较股票；逐日统计才能正确计算标准误。
- **后果**：混池结果已删除、不得引用；后续 t 值仍需处理持有期重叠。

### D7. 执行假设

- **决定**：t 日收盘生成信号，t+1 日开盘成交；A 股不做空，因此“多空组合”只用于研究，实盘版本只做多头。
- **理由**：避免用 t 日收盘价成交造成未来函数；尊重 A 股无便利融券的现实。
- **后果**：必须同时报告“研究组合（多空）”和“可执行组合（多头 + 现金）”。

### D8. 工程形态

- **决定**：`configs/` 管参数，`src/` 只放主线脚本，`results/` 存结果，原始数据与处理数据分离。
- **当前形态**：`download_data → build_panel → build_signals → evaluate_cross_section`；历史一次性脚本已删除。
- **后果**：换机器按 README 顺序即可重跑，数据不进 Git。

### D9. 文档体系（2026-10-28）

- **背景**：项目需要可追溯的决策记录，并用于简历。
- **决定**：只保留 `PROJECT_MEMORY.md` 作为唯一项目文档，加 `RESUME.md` 与两份数据报告；过程类文档已删除。
- **理由**：文档太多会让维护成本超过研究本身，单一事实来源更可靠。
- **后果**：口径与状态只改这一份；数据报告只记录可核对的事实。

## 4. 研究设计（当前版本）

### 4.1 核心研究问题

1. A 股是否存在短期反转效应？
2. 不同形成期（1/5/20 日）与持有期（1/2/5 日）下，效应有何差异？
3. 行业调整后，反转是否仍存在？
4. 高波动与低波动市场中，反转强度是否不同？
5. 扣除交易成本、考虑停牌/涨跌停后，策略是否有正的样本外收益？

### 4.2 四个可证伪假设

| 编号 | 假设 | 检验方法 | 判定标准 |
|---|---|---|---|
| H1 | 短期反转存在 | 逐日按过去 k 日收益分 30%/70%，比较未来 h 日收益 | 反转差 > 0 且统计显著 |
| H2 | 剔除行业共同波动后仍存在 | 用个股收益减去行业均值，重建信号 | 行业调整后反转差仍显著 |
| H3 | 市场状态会改变反转强度 | 用指数过去 20 日已实现波动率划分高/低波动 | 两组差异有经济与统计意义 |
| H4 | 扣费后仍有净收益 | 按 5/10/20 bps 单边成本回测 | 净收益 > 0 且换手可承受 |

### 4.3 实验矩阵

| 实验 | 信号 | 持有期 | 目的 |
|---|---|---|---|
| E0 | 随机分组/无信号基准 | 1、5 日 | 检查流程与对照组 |
| E1 | 过去 1 日收益反转 | 1、2、5 日 | 极短期反转 |
| E2 | 过去 5 日收益反转 | 1、2、5 日 | 短期反转主检验 |
| E3 | 过去 20 日收益反转 | 1、2、5 日 | 不同形成期 |
| E4 | 行业调整后的 1、5 日收益 | 1、2、5 日 | 排除行业驱动 |
| E5 | 加入市场状态 | 1、2、5 日 | 条件效应 |

**预注册原则**：以上 9 个“形成期 × 持有期”组合全部报告，不只报最好看的那个。

### 4.4 评价指标

| 类别 | 指标 | 用途 |
|---|---|---|
| 收益 | 年化收益、累计收益、相对基准 | 判断经济意义 |
| 风险 | 年化波动、最大回撤、Sharpe、下行风险 | 判断风险调整后表现 |
| 交易 | 换手率、单边成本、净收益、盈亏平衡成本 | 判断可交易性 |
| 统计 | t 值、置信区间、分组单调性、样本外表现 | 判断证据强度 |

### 4.5 时间切分

| 阶段 | 区间 | 用途 |
|---|---|---|
| 开发/训练 | 2015–2018 | 探索信号、确定参数 |
| 验证/选择 | 2019–2021 | 比较少量预选方案 |
| 最终样本外 | 2022–2025 | 冻结参数后只跑一次 |

### 4.6 成本假设

- 单边成本情景：**5 bps（低）、10 bps（中）、20 bps（高）**。
- 成本模型：`净收益 = 毛收益 − c × Σ|w_t − w_{t−1}|`，其中 c 为单边成本，w 为权重。
- 必须同时报告毛收益、净收益、换手率与盈亏平衡成本。

### 4.7 市场状态定义

- 使用**指数过去 20 个交易日已实现波动率**：`σ = Std(r_{t−19}, …, r_t)`。
- 阈值只能用训练期确定，然后固定用于样本外；不能用未来波动率。
- 每个状态都要报告样本量与置信区间，避免小样本过度解读。

### 5.2 数据规则

1. 股票代码必须按**字符串**处理，`000001` 不能变成 `1`。
2. 同一股票同一交易日只能有一条记录。
3. 原始数据、标准化数据、信号数据分层保存，不覆盖原始文件。
4. 每次下载记录：接口、参数、记录数、缺失数、文件哈希。
5. 复权口径必须统一：优先使用**后复权收盘价**计算收益；如需用不复权价，必须单独说明。
6. 当前股票池是**参考日（2026-10-27）快照**，不是历史成分，存在幸存者偏差。

## 6. 术语表

| 中文 | 英文/代码 | 含义 | 易混淆点 |
|---|---|---|---|
| 形成期 | formation period | 用过去多少天的收益构造信号 | 不是持有期 |
| 持有期 | holding period / horizon | 信号后持有多少天 | 与形成期独立 |
| 反转收益差 | reversal spread | 输家组未来收益 − 赢家组未来收益 | 正值才叫反转 |
| 输家组 | loser group | 过去收益最低的 30% | 不是“亏损股” |
| 赢家组 | winner group | 过去收益最高的 30% | 不是“赚钱股” |
| 横截面 | cross-section | 同一交易日内的股票比较 | 不是时间序列 |
| 混池 | pooled sample | 把不同日期混在一起分组 | **错误做法**，已废弃 |
| 未来函数 | look-ahead bias | 使用了决策时点拿不到的信息 | 最致命错误 |
| 幸存者偏差 | survivorship bias | 只用今天还活着的股票回溯 | 高估历史收益 |
| 前复权/后复权 | forward/backward adjustment | 调整历史价格以处理分红送股 | 后复权更适合算收益 |
| 换手率 | turnover | 组合调仓比例 | 直接影响成本 |
| 盈亏平衡成本 | break-even cost | 净收益为 0 时的单边成本 | 衡量策略脆弱性 |
| 已实现波动率 | realized volatility | 过去 20 日收益率标准差 | 市场状态代理变量 |
| 样本外 | out-of-sample | 参数冻结后未见过的数据 | 不能反复调参 |

## 10. 红线与踩坑清单

1. **未来函数**：信号只能用 t 日收盘及之前的数据；成交必须假设 t+1 开盘。
2. **混池分组**：必须先按日期分组，再在组内排序；跨日混池一律视为错误。
3. **未复权价格**：不能用于正式收益；分红送股会制造假信号。
4. **幸存者偏差**：当前股票池是今天活着的股票，不能声称代表历史全市场。
5. **重叠持有期**：2 日、5 日持有期会重叠，普通 t 检验高估显著性。
6. **多重检验**：9 组参数全报，不能只挑最好的；必要时做 Bonferroni 或 FDR。
7. **小样本**：每天少于 30 只股票时，分位数不稳定，结论只能算探索。
8. **数据混用**：不同数据源的复权价、成交量单位可能不同，不能拼接。
9. **结果文件命名**：不要用拼写错误的文件名进入正式报告。
10. **提交数据**：`data/raw`、`data/processed` 不进 Git；只提交代码、配置、质量报告和小体积结果表。
